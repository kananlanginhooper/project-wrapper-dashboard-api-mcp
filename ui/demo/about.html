Home dashboards

A demo of the wrapper: the tabs above are separate apps, each running on its own and shown here in an iframe.

How it works

  • The wrapper is a small Angular shell with a FastAPI back end. It knows nothing about the apps inside it, only their titles and addresses.
  • The tab list comes from a Postgres table, with an address per environment (laptop, server, later one subdomain per app), or from a JSON file.
  • Each app stays a complete project that runs without the wrapper. It allows the wrapper's address to frame it, and nothing else.
  • Sign-in will be single sign-on through a small self-hosted OpenID Connect provider: each app is its own client (authorization code + PKCE).

In this demo

There's no back end: the tab list is a static file, and each tab is that project's own public demo running on mock data.
